## ⚙️ Customizing Shortcuts

Keyboard shortcuts can be customized through the Settings application:

1. Open **Settings** from Start menu
2. Navigate to **Keyboard Shortcuts**
3. Click on any shortcut to rebind
4. Press your desired key combination
5. Click **Save** to apply changes

**Note:** Some system shortcuts cannot be changed for security reasons.

## 💡 Tips & Tricks

### Power User Tips
1. **Chain shortcuts**: Combine workspace switching with window snapping for ultra-fast window management
2. **Global search**: Use `Ctrl+Space` to search and launch anything instantly
3. **Quick actions**: `Ctrl+Shift+A` provides one-click access to common tasks
4. **Terminal mastery**: Learn `Ctrl+R` for history search to speed up command execution

### Mobile/Touch Devices
On touch devices without physical keyboards:
- Long-press for context menus
- Swipe gestures replace some shortcuts
- Use the virtual keyboard in Terminal app
- Quick actions panel provides touch-friendly alternatives
