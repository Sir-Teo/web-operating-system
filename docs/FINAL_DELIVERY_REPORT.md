### Quick Start

1. **Open Command Palette**: Press `Cmd+K` or `Ctrl+K`

2. **Type Natural Commands**:
   ```
   "open terminal"
   "create file document.txt"
   "find files containing example"
   "minimize all windows"
   "take screenshot"
   ```

3. **Access via JavaScript**:
   ```javascript
   // Get the next-gen kernel
   const kernel = window.nextGenKernel;

   // Use AI Assistant
   await kernel.getAIAssistant().processCommand('open calculator');

   // Access any component
   const marketplace = kernel.getMarketplace();
   const cicd = kernel.getCICD();
   const containers = kernel.getContainerRuntime();
   ```
